# HorizonX · Amazon Fire OS

Solo Fire OS Android (7/8), ADB y Python. Instalar es distinto de activar Home; home-plan guarda el respaldo y token. home-restore revierte la activación.

Android-based Fire OS (7/8) only, ADB and Python. Installation and Home activation are separate; home-plan creates a backup/token. home-restore reverses activation.

```sh
python3 otras-plataformas/amazon-fireos/installer/horizonx_fire.py --help
```
