# HorizonX 3.4.0 · asistente de instalación

Necesita Python 3.10+ y Android Platform Tools. Abre HorizonX.sh (Linux/macOS) o
HorizonX.cmd (Windows); el menú permite conectar, instalar la APK, optimizar y restaurar.
Los scripts Python son únicamente el asistente ADB; el proyecto Android no está incluido.
La APK está en ../dist/HorizonX-3.4.0.apk al descargar el repositorio, o junto al asistente
si utilizas el ZIP de PC. No necesitas Gradle, Android Studio, JDK ni compilar HorizonX.

Guía: https://github.com/2207juan/HorizonX/blob/main/docs/GUIA.md
